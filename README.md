## Search indexing

- `robots.txt` allows crawling and points crawlers to `sitemap.xml`.
- Submit `https://advkathleharishkumar.in/sitemap.xml` in Google Search Console.
- Verify the domain property in Search Console using the DNS TXT record Google provides.
- Use URL Inspection to request indexing of `https://advkathleharishkumar.in/`.

Google decides when and how pages appear in search results; SEO changes cannot guarantee a particular ranking.
